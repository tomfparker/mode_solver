# refractiveindex.info source files

Copied verbatim from the refractiveindex.info database
(https://github.com/polyanskiy/refractiveindex.info-database, CC0 1.0), retrieved 2026-10-05.
`scripts/import_materials.py` converts them into `data/materials/*.json`. Don't hand-edit
the JSON coefficients; change the import script and re-run it.

Formula definitions: `database/doc/Dispersion formulas.pdf` in that repository
(formula 1 = Sellmeier with squared poles, 2 = Sellmeier with unsquared poles, 6 = gases).
